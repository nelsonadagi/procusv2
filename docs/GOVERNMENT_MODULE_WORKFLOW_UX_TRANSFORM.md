# Government Procurement, Compliance Review, and Tender Oversight -- Workflow-First UX Transformation

**Module:** Government / Public Procurement Workspace  
**Date:** 2026-05-17  
**Status:** Design Blueprint — Ready for Review

---

# 1. MODULE EXPERIENCE VISION

## What the User Is Trying to Accomplish

A government user is trying to **publish, review, award, and oversee procurement work with visibility and compliance**.

The module should reduce ambiguity around tender state, approvals, and compliance blockers.

---

# 2. USER GOALS

### Primary Goals
1. Publish tenders
2. Review bids
3. Award contracts
4. Monitor compliance and delivery

### Urgent Goals
5. Fix blocked tenders
6. Review missing documentation
7. Escalate delays or disputes

---

# 3. WORKFLOW-FIRST UX REDESIGN

| Stage | What User Sees | Main CTA | Secondary Actions | Blockers | Guidance |
|---|---|---|---|---|---|
| Tender Draft | tender setup | Publish tender | save draft | missing specs | show mandatory fields |
| Live Tender | active submissions | Review bids | clarify scope | no bids | recommend next action |
| Evaluation | comparison and scoring | Shortlist bidders | request clarification | incomplete compliance | show decision support |
| Award | award status | Issue award | notify bidders | approvals pending | explain downstream steps |
| Oversight | contract and delivery tracking | Review progress | escalate | missed deadlines | show timeline and risk |

---

# 4. FINAL UX TRANSFORMATION SUMMARY

The government workspace should make procurement state obvious, approvals visible, and escalation paths clear.
