# PROPERTY_TAXONOMY.md

## Phase 4+ — Property And Development Asset Taxonomy

This document defines the target classification system for property listings.

The taxonomy should support:

* standalone property discovery
* property-manager operations
* project origination from a property
* financing and investment review
* downstream procurement decisions when a property becomes a project

---

* Residential Land
* Commercial Land
* Mixed-Use Land
* Industrial Land
* Agricultural Land for Future Development
* Institutional Land
* Special Economic Zone Parcel
* Greenfield Development Site
* Brownfield Redevelopment Site
* Fully Serviced Plot
* Partially Serviced Plot
