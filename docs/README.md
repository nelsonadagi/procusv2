## For AI Agents / LLMs

When asked to implement a feature:
1. Check [`WORKFLOW_UX_IMPLEMENTATION_SPEC.md`](./WORKFLOW_UX_IMPLEMENTATION_SPEC.md) first — it contains the exact file paths, status, and acceptance criteria.
2. If the feature is missing from the spec, refer to the module's blueprint (e.g., `VENDOR_MATERIAL_WORKFLOW_UX_TRANSFORM.md`).
3. Always follow the component naming convention in Appendix A of the spec.
