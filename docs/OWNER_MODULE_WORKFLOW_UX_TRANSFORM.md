# Owner Property Publishing, Lead Response, and Asset Control -- Workflow-First UX Transformation

**Module:** Owner / Property Control Workspace  
**Date:** 2026-05-17  
**Status:** Design Blueprint -- Ready for Review

---

# 1. MODULE EXPERIENCE VISION

## What the User Is Trying to Accomplish

A property owner is trying to **publish, maintain, and progress their asset** without needing to understand the platform's internal structure.

The system should make ownership feel like a guided operational flow: publish, respond, update, and move forward.

## Emotional / Operational State

| Actor | Emotional State | Operational State |
|---|---|---|
| **New Owner** | Unsure, wants reassurance | Has an asset but not a workflow |
| **Active Owner** | Busy, wants clarity | Needs lead response and listing upkeep |
| **Portfolio Owner** | Task-heavy, repeat user | Manages multiple listings and progress states |

## What Makes the Current UX Difficult

1. Owners may not know where to start.
2. Listings and inquiries can feel disconnected.
3. The system can show data without telling the owner what is blocked.
4. Media, documents, and availability are often treated as separate chores.

## What the Ideal Workflow Should Feel Like

> "The system keeps my property ready, tells me who is waiting on me, and shows me the next step without forcing me to look for it."

# 2. USER GOALS

## Owner

### Primary Goals
1. Publish a complete listing
2. Respond to inquiries quickly
3. Keep availability current
4. Move strong opportunities into project or finance workflows

### Secondary Goals
5. Upload media and documents
6. Review performance metrics
7. Reuse listing patterns

### Urgent Goals
8. Fix blocked listing fields
9. Respond to a buyer or investor
10. Refresh stale listing data

# 3. WORKFLOW-FIRST UX REDESIGN

| Stage | What User Sees | Main CTA | Secondary Actions | Blockers | Guidance |
|---|---|---|---|---|---|
| Draft | property setup checklist | Continue setup | save draft | missing required fields | show the next incomplete section |
| Publish Ready | readiness snapshot | Publish listing | add media | incomplete trust signals | explain what unlocks visibility |
| Active Leads | live inquiry queue | Respond now | publish availability | unanswered leads | highlight urgency |
| Portfolio Maintenance | health indicators | Refresh listing | duplicate listing | stale data | suggest updates |
| Project/Finance Link | opportunity handoff | Open linked workflow | create project | missing project record | explain next destination |
