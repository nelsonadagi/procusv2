# Project Planning, Procurement, Execution, and Milestone Control -- Workflow-First UX Transformation

**Module:** Project / Delivery Workspace  
**Date:** 2026-05-17  
**Status:** Design Blueprint -- Ready for Review

---

# 1. MODULE EXPERIENCE VISION

## What the User Is Trying to Accomplish

A project user is trying to **turn an idea or property opportunity into a managed delivery path** with clear procurement, milestones, approvals, and closure.

---

# 2. USER GOALS

### Primary Goals
1. Create or review a project
2. Attach procurement and contractors
3. Track milestones and approvals
4. Close the project cleanly

### Urgent Goals
5. Recover from blocked milestones
6. Resolve missing payments or approvals
7. Detect slippage early

---

# 3. WORKFLOW-FIRST UX REDESIGN

| Stage | What User Sees | Main CTA | Secondary Actions | Blockers | Guidance |
|---|---|---|---|---|---|
| Draft | project setup | Continue setup | save draft | missing scope | show next required field |
| Procurement | supplier and contractor actions | Request quotes | compare bids | no bids | recommend next step |
| Execution | milestone timeline | Approve milestone | update progress | overdue work | show who is waiting |
| Handover | completion state | Close project | archive | pending signoff | explain final checks |

---

# 4. FINAL UX TRANSFORMATION SUMMARY

The project workspace should keep delivery moving from setup to procurement to milestone approval without forcing users to hunt for the next task.
