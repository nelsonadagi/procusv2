# Backend Feature Prompt

```md
Implement a backend feature in the Django codebase for this repository.

Start by reading:
- `context/02-architecture.md`
- `context/04-backend-context.md`
- `context/06-data-and-taxonomy.md`
- `context/07-workflows.md`
- `context/08-security-compliance-and-risk.md`

Then:
- identify the correct Django app for the change
- inspect models, serializers, views, permissions, URLs, and tests in that app
- confirm whether the feature belongs in a versioned route or an app-level route
- preserve role-based access control
- account for workflow status transitions and auditability if money, approvals, or compliance are involved
- add tests for the expected behavior

Deliver:
- implementation
- endpoint contract
- permission model
- tests added or updated
```
