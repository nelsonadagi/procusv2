# Full-Stack Feature Prompt

```md
Implement a full-stack feature in this repository.

First:
- Read `context/01-platform-overview.md`
- Read `context/04-backend-context.md`
- Read `context/05-frontend-context.md`
- Read `context/07-workflows.md`
- Read `docs/VENDOR_INVENTORY_SYSTEM.md` when the feature touches supplier inventory or order-linked stock

Task requirements:
- determine which backend app should own the feature
- determine which frontend view, component, or dashboard should expose it
- confirm the correct API namespace and payload shape
- preserve the existing project structure and styling direction
- avoid introducing duplicate business logic in multiple apps
- add or update tests where practical
- explain any assumptions made
- if inventory is involved, prefer movement-based reconciliation over silent raw quantity edits

Deliver:
- code changes
- affected files
- how the feature fits the existing workflow
- any follow-up risks or gaps
```
