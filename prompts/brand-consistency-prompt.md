# Brand Consistency Prompt

```md
Audit and improve brand consistency for a page, flow, or component in this repository.

Read first:
- `context/16-design-principles.md`
- `context/18-brand-application-rules.md`
- `frontend/FRONTEND_STYLE_GUIDE.md`

Then inspect the target files.

Your job:
- identify where the design drifts from the Paanguzo brand
- identify conflicting visual languages
- correct typography, color use, panel structure, and interaction styling
- keep the result premium, industrial, and coherent

Deliver:
- the main consistency issues found
- the fixes implemented
- any remaining brand drift that should be handled later
```
