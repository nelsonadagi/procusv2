# Prompts Folder

This folder contains reusable prompts you can paste into Codex, ChatGPT, or another implementation assistant while working on this codebase.

Each prompt assumes:

- the repository contains a Django backend and Vue frontend
- the `context/` folder is the preferred starting point for project understanding
- source docs in `docs/` can be used when deeper detail is required

## Suggested usage order

1. Start with `project-bootstrap-prompt.md`
2. Use a task-specific prompt from the rest of the folder
3. After implementation, run `testing-and-verification-prompt.md`
4. Use `documentation-sync-prompt.md` to keep context and docs aligned
