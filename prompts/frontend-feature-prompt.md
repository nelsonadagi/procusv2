# Frontend Feature Prompt

```md
Implement a frontend feature in the Vue application for this repository.

First read:
- `context/02-architecture.md`
- `context/05-frontend-context.md`
- `context/07-workflows.md`

Then:
- inspect the relevant view, router entry, store, API service, and shared components
- preserve the current visual language and dashboard patterns
- confirm the backend endpoint exists before wiring the UI
- keep state handling simple and consistent with existing Pinia usage
- support mobile layouts where relevant
- avoid hardcoding API paths that conflict with the established namespace

Deliver:
- UI implementation
- any API calls added or changed
- route/store/component changes
- notes about any backend dependency
```
