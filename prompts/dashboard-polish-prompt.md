# Dashboard Polish Prompt

```md
Polish a dashboard in this repository so it feels like part of a single operational platform.

Read first:
- `context/16-design-principles.md`
- `context/17-ui-patterns.md`
- `context/18-brand-application-rules.md`
- `context/19-page-priorities.md`

Your goal:
- normalize the dashboard shell
- unify header, sidebar, stat card, content panel, and table patterns
- strengthen operational clarity
- preserve the role-specific content while improving consistency with other dashboards

Check for:
- inconsistent spacing
- mixed badge styles
- weak hierarchy
- noisy surfaces
- unclear primary actions

Deliver:
- polished dashboard implementation
- notes on shared patterns that should be reused elsewhere
```
