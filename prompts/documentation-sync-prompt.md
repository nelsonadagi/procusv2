# Documentation Sync Prompt

```md
Update the documentation and context for this repository after a change.

Start with:
- `context/README.md`
- `context/10-source-map.md`

Then:
- inspect the code changes
- identify which files in `context/` should be updated
- identify which source docs in `docs/` are now stale
- update summaries so they reflect the implementation accurately
- keep the curated context concise and practical

Deliver:
- updated context files
- any updated source docs
- a short summary of what changed
```
