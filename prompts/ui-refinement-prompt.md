# UI Refinement Prompt

```md
Refine the look and feel of a specific page or feature in this repository.

Read first:
- `context/16-design-principles.md`
- `context/17-ui-patterns.md`
- `context/18-brand-application-rules.md`
- `context/19-page-priorities.md`

Then inspect the target page and its shared components.

Your goal:
- improve hierarchy, spacing, surfaces, and interactions
- preserve functionality
- keep the page aligned with the Paanguzo design system
- avoid random one-off visual tricks

Focus on:
- page structure
- typography
- CTA clarity
- cards and tables
- empty/loading states
- mobile usability

Deliver:
- refined implementation
- summary of visual improvements
- any shared component dependencies
```
